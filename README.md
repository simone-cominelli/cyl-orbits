# Simulatie single particle motion in a given magnetic field configuration
The code is created from scratch and aims to test a new method for solving close orbits trajectory. It solves one dimensional dynamics, 2D differential equation in the phase space, using the energy as a constant of motion to reduce the dimensionality. Which means that the energy conservetion is used to picture the trajectory (x,v)(t) in the phase space, and then the time dependence is solve via numerical method for differential equation. Furthermore, it exploits the symmetry (v,t) -> (-v,-t) of the trajectory by solving the motion in the negativ v-semiplane from the given motion in the upper plane.
